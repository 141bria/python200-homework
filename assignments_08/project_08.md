Scenario A costs $1.81 per month, while Scenario B costs $2,570.16 per month. The cost of Scenario B genuinely surprised me. I didn't realize that using multiple cloud services could be so expensive.
Scenario A only required one instance with low RAM and CPU, and it only ran for a certain amount of hours. However, Scenario B required three services, including a powerful GPU instance that runs 24/7, which contributed to the higher cost. I think using a GPU would be worth it for something that requires a lot of computing power, like training AI models, but wouldn't be necessary for smaller tasks.
